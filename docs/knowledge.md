# Knowledge 只读索引

功能分支提供显式查询的项目知识索引。设置 `CODEAGENT_KNOWLEDGE=1` 后注册 `knowledge_search` 与 `knowledge_get`，默认关闭；使用 `AppConfig(knowledge_enabled=True)` 也可开启。配置仅接受布尔值，环境开关仅接受 `0`/`1`。Agent 与 Skill 的工具白名单继续生效，注册不代表每个 Agent 都获准调用。

Knowledge 回答“当前项目在哪里定义、写了什么”，长期 Memory 保存跨任务经验，官方 MCP Memory 图谱属于候选文件产物，三者独立。索引只保存可重建的派生数据，不参与任务恢复、独立验收或发布判定，不自动向每轮上下文注入内容，也不调用模型、向量服务或外部网络。

## 查询与引用

```json
{"query": "SandboxExecutor", "kind": "symbol", "limit": 5}
```

`kind` 可为 `all`、`path`、`symbol`、`document`。文件路径、Python AST 定义（含类、异步函数及限定名称）和 Markdown/RST/TXT 非空段落构成索引。Python 内容只做静态解析，不导入项目模块；语法错误文件仍能按路径查找，`invalid_python` 明确计数。二进制、非 UTF-8 文件不收录，空文件不产生可引用段落。

查询采用字面词项全部匹配，符号名称和路径优先，内容匹配次之，最后按路径和行号稳定排序。支持 Unicode 文本，不提供语义检索或任意正则。查询最长 256 字符，返回最多 20 项。每项包含路径、行号、文件 SHA256 和整个可检索内容集的 `index_version`；片段最多20行、前2000字符参与内容匹配与预览，截断会明确标记，余文不作为本片段的搜索词项。需要更完整内容时使用引用读取或原有工具。

把搜索结果的以下五个字段原样交给 `knowledge_get`：

```json
{
  "path": "codeagent/tool/executor.py",
  "start_line": 148,
  "end_line": 167,
  "file_sha256": "<搜索返回的64位摘要>",
  "index_version": "<搜索返回的64位内容版本>"
}
```

示例行号仅展示格式，应使用实际返回值。读取再次检查当前内容集、文件摘要及行号，最多读取 40 行、16KiB；修改、删除、重命名、分支内容切换或忽略规则变化后，旧引用拒绝并要求重新搜索。搜索也可传 `expected_version`，要求绑定已知版本；即使只改其它收录文件，整个索引版本变化也会使旧引用失效。摘要反映内容，不能证明任意来源可信；返回文字仍是低权限 ToolResult，不能授予工具权限或覆盖系统规则。

## 候选与增量更新

Podman 模式下，固定辅助源码在注册时由控制面读取，使用可信镜像内的 `python -I` 在当前 `/workspace` 查询；不回退宿主读取。每个 SandboxExecutor 的缓存独立存于控制面内存，关闭执行域后旧句柄不能再查询。当前候选可能与主机文件不同，结果始终来自该容器。辅助程序不创建索引文件，容器 seal 后候选中没有索引副产物。

本地模式使用隔离 Python 子进程读取当前授权工作目录；不把本地进程隔离等同于 Podman。缓存按执行器及工作目录划分。工具批次设为串行，避免同一批次的写操作与读取交错；Podman 管理器继续串行化同一域的命令。外部进程仍可能修改本地文件，读取检查文件前后的大小/时间，结果引用应在使用前重新验证，不能视为整仓库的原子锁。

每次重新枚举范围并读取内容计算 SHA256，不依靠 mtime 判断有效性。未变文件复用此前的符号/段落提取，改变文件重新解析，删除或忽略的路径移出缓存。`rebuilt`、`reused`、`removed`、`hashed_bytes` 区分工作量：这是增量解析，扫描和哈希仍与当前范围大小相关。缓存只存派生结果，不成为恢复权威或项目发布产物。

## 范围与失败边界

默认排除所有隐藏路径（`.gitignore` 仅用于过滤，不返回内容）、`.private-docs`、`.codeagent`、`.env`、依赖/构建目录，以及常见凭据名称和密钥后缀。符号链接、Windows 重解析点、硬链接与特殊文件不进入索引。POSIX 文件读取使用 dirfd/O_NOFOLLOW 防止路径组件被替换为链接。任意命名的明文秘密无法单靠文件名识别，操作者仍应通过忽略规则或授权候选输入排除。

当前 `.gitignore` 过滤是保守子集：支持根/嵌套文件、目录模式、逐段 `*`/`?`/字符类与 `**`，否定规则不会重新开放已排除路径；反斜杠转义等不支持的语法直接拒绝查询。它不是完整 Git wildmatch 实现。本地查询不读取宿主全局 excludes 或 `.git/info/exclude`；Podman 的初始 Git 输入仍受既有快照准入过滤，容器内新增路径另按当前规则筛选。

范围最多 1024 个 UTF-8 文件、8MiB 已读内容；每个合格文件最多 256KiB，最多 8192 条索引记录，传输包最多 4MiB。超限或策略解析失败使查询报错，不返回看似完整的部分索引。原有 `read_file`、`grep` 仍可使用。没有磁盘索引持久化、跨会话共享、向量检索、自动注入或自动修改项目。

验收与检索对照见[Knowledge 测试](testing/knowledge.md)。
