# 模型与上下文测试

验收基线和全量结果见[最新测试总览](README.md)；机制与配置见[模型与上下文](../model-and-context.md)。
本页将同类路由、预算、压缩和校准测试整合为当前能力判据，不累计历史阶段数字。

## 路由、费用与能力

| 测试主题 | 判据 | 用例入口 |
|---|---|---|
| 角色与备用链 | 七类角色配置、Provider 注册/规范化、显式链与错误分类；取消不触发 fallback | [角色路由](../../tests/test_model_routing.py) |
| 计价与未知项 | 输入/输出/缓存分别计价，精确整数累计；非法金额、缺价格或用量不完整不当零 | [成本路由](../../tests/test_cost_routing.py) |
| 同步成本与恢复 | 调用意图先记账、失败阻止请求；并发无丢失、resume 同 run 续计，旧覆盖缺口保留 | [成本路由](../../tests/test_cost_routing.py) |
| Worker 经济模型 | 只降级 Worker，其他角色保留；工具/图片/窗口不兼容保留主模型 | [成本路由](../../tests/test_cost_routing.py)、[能力](../../tests/test_model_capabilities.py) |
| 实际候选能力 | 保留用户较小窗口/输出、省略不支持的温度；主模型拒绝、备用跳过、缺元数据/冲突拒绝 | [能力](../../tests/test_model_capabilities.py) |
| 观测 | 事件故障不改预算决定，角色/模型归因、同步成本与轨迹可核对 | [观测](../../tests/test_observability.py)、[用量接线](../../tests/test_llm_metrics_wiring.py) |

这些测试使用固定 Provider 和虚构价格，证明计价、路由与门禁逻辑，不证明供应商实际账单、真实省钱比例或质量不降。

## 压缩与完整请求预算

| 测试主题 | 判据 | 用例入口 |
|---|---|---|
| Worker 上下文 | 计入工具和输出预留，依据实际模型窗口准备消息 | [能力](../../tests/test_model_capabilities.py)、[上下文](../../tests/test_context_manager.py) |
| Map 请求 | 序列化包装与转义、System/Focus/输出/修复均计入；完整工具 turn 不拆碎 | [压缩预算](../../tests/test_compaction_budget.py) |
| Reduce 分批 | 顺序固定、版本只发布一次；后批异常、截断、膨胀或耗尽不发布中间状态 | [压缩预算](../../tests/test_compaction_budget.py)、[压缩器](../../tests/test_history_compactor.py) |
| 超长输入 | 单 turn/delta 或检查点无法装入时明确失败，保留历史，不无限重试 | [压缩预算](../../tests/test_compaction_budget.py) |
| 并发与取消 | Map 乱序完成不改变历史顺序；取消排空，正常与应急共享批次预算 | [压缩预算](../../tests/test_compaction_budget.py) |

最新全量含 **31 个压缩预算用例**。它们验证窗口规划和失败回退，尚不证明真实模型摘要语义无损。

## Planner / Verifier 与完整证据

最新全量含 **56 个预算/证据用例**，主要入口为[验收预算](../../tests/test_verification_budget.py)。

- Planner 保留原始任务，超限和明确供应商上下文错误停止，不通过裁剪要求或单 Step 回退绕过门禁；JSON 修复、超时与外部取消有界。
- LocalVerifier 保留原始步骤目标；严格布尔、截断、缺字段、不可用与超限不能放行，无法判定时不反思、不回传。
- Git 与非 Git 完整证据覆盖尾部大 diff、中文/空格/字面特殊路径、模式/空文件变化与完整 hunk，不用展示前缀代替验收。
- 二进制创建/修改/删除的元数据绑定冻结内容摘要；无独立确定性检查不能接受。
- 每批 checked_ids 完整唯一，遗漏/重复/不属于本批均拒绝；后批异常和整体验收拒绝不能被先前通过覆盖。
- 单块超限、证据额度耗尽、报告膨胀或采集失败均不推进真实 base。

另有 **4 个真实 Podman 验收场景**位于[完整验收容器](../../tests/test_verification_podman.py)：局部无法判定、证据遗漏、整体验收拒绝和正常接受。
容器场景包含在 36 个真容器用例与 VM 全量中。模型响应固定，编号覆盖不等于语义证明。

## E10 保守校准

最新全量含 **38 个校准单元用例**：[token 校准](../../tests/test_token_calibration.py)。覆盖：

| 类别 | 判据 |
|---|---|
| 基数与隔离 | 中英文/代码、完整工具 JSON；Provider/模型和图片/工具协议类别隔离，原消息缓存不混入倍率 |
| 计数目标 | 七类角色、实际备用候选和 SDK 序列化按正确 Provider/模型计数 |
| 采样边界 | 70% 边界、超窗直接拒绝；缓存、间隔、每类别/会话额度及类别容量有界 |
| 并发 | 等待同类别正在执行的采样，再按新倍率重查，即使原估算较小 |
| 样本与失败 | 无效整数/布尔/零值、不支持、异常/超时保守回退；取消传播并释放锁 |
| 倍率与观测 | 历史安全倍率不降低，轨迹与指标记录结果，不混入生成用量 |
| 原门禁 | 局部超窗停止反思/回传，全局超窗不发布，失败保留历史 |

**2 个真实容器校准门禁用例**位于[校准门禁容器](../../tests/test_token_calibration_podman.py)，验证校准后的局部/全局拒绝不会发布成果，并完成清理。
它们属于全量和真容器总数，不另加总。

## 当前结论与下一阶段

最新结果支持模型适用性、请求组织、有限采样和失败门禁按测试判据工作。
精确样本只对应当次完整请求；倍率只上调可能增加压缩，不能据此推断 token 减少、费用下降或真实质量改善。
计数接口费用未完整进入生成成本表，不能标为免费。

下一阶段先补成对运行与报告，再固定任务、输入基线、Provider、模型和参数比较关闭/开启校准，并重复运行观察波动。
记录估算误差、计数调用、压缩、产物确定性验收、生成用量、费用和延迟，不支持/未知项明确标记。
最终质量依据真实产物判据，不能仅用 LLM 自述或“任务期望成功却未成功”推断 Verifier 假拒绝。
已有[场景与 benchmark](../../scenarios/README.md)是显式运行入口；当前尚未接入 SWE-bench，也未完成精确假拒绝归因。
